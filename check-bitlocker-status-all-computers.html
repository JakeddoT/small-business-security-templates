How to check BitLocker is on, on every PC in a small office

By William Todd, IT support and cybersecurity engineer · Updated 2026-11-21

Open PowerShell as administrator and run Get-BitLockerVolume -MountPoint C:. If ProtectionStatus says On and VolumeStatus says FullyEncrypted, that PC is protected. Anything else needs attention. Then do it for every laptop and desktop, and check the recovery key is saved somewhere other than the PC itself.

Why it matters: an unencrypted stolen laptop can turn into a reportable data breach, and cyber insurers and auditors routinely ask whether laptops are encrypted. "I think so" isn't evidence.

Check one PC (2 minutes)

Right-click Start, choose Terminal (Admin) or Windows PowerShell (Admin), and run:

Get-BitLockerVolume -MountPoint C: | Select-Object MountPoint, VolumeStatus, ProtectionStatus, EncryptionPercentage

Or, in any admin Command Prompt:

manage-bde -status C:

How to read the result

What you seeMeaningAction
FullyEncrypted, Protection OnProtectedConfirm the recovery key is backed up (below)
FullyEncrypted, Protection OffEncrypted but suspended: the key is stored in the clear, so the encryption isn't protecting anythingRun Resume-BitLocker -MountPoint C:, then check again
EncryptionInProgressStill encryptingLeave it on and plugged in, re-check tomorrow
FullyDecrypted, Protection OffNot encryptedTurn on BitLocker (or Device encryption on Home), after saving the recovery key
"Get-BitLockerVolume is not recognized" or access deniedNot elevated, or Windows HomeRe-run as administrator; on Home, check Settings → Privacy & security → Device encryption

Suspended protection is the one people miss. Windows or a technician can suspend BitLocker for a firmware or BIOS update, and it doesn't always get resumed. The drive still shows as encrypted, but anyone with the laptop can read it.

Confirm the recovery key is saved

Encryption without a recoverable key is a different disaster: one motherboard repair and your data is gone. For each PC, confirm the key is stored in one of these:

  • Microsoft Entra ID (Microsoft 365 business devices): Entra admin center → Devices → select the device → BitLocker keys. Intune also shows an encryption report for managed devices.
  • Active Directory, if you have an on-premises domain.
  • The user's Microsoft account (common on PCs set up as personal devices). That's a risk for a business, because the key leaves with the employee.
  • A password manager entry or locked record, if none of the above apply. Never in a file on the same PC.

To see which key protectors exist on a PC (read-only), run manage-bde -protectors -get C:. The Numerical Password ID should match a key you can find in your records.

Check every PC in the office

For 3–30 computers, the practical options are:

  1. Your RMM or Intune. If an MSP manages your PCs, ask for the encryption report. It takes them minutes.
  2. A quick script on each PC. The free Windows Quick Security Check reports BitLocker along with Defender, firewall, patch age, RDP and SMBv1 as PASS / WARN / FAIL, and can save an HTML report to keep as evidence.

Common mistakes

  • Checking only laptops. Desktops get stolen in break-ins too, and front-desk PCs often hold the most customer data.
  • Forgetting external drives. USB backup drives with customer data need BitLocker To Go or another encrypted option.
  • Turning it on before saving the key. Save and verify the recovery key first.
  • Assuming new PCs come encrypted. Many do, but not all, and setup through a personal Microsoft account puts the key in the wrong place.

Frequently asked questions

How do I check if BitLocker is enabled with PowerShell?

Open PowerShell as administrator and run Get-BitLockerVolume -MountPoint C:. ProtectionStatus On with VolumeStatus FullyEncrypted means the drive is protected.

What does BitLocker protection suspended mean?

The drive is encrypted but the key is stored unprotected, so the encryption isn't protecting the data. Run Resume-BitLocker -MountPoint C: in an elevated PowerShell window and check again.

Does Windows 11 Home have BitLocker?

Windows Home doesn't include full BitLocker management, but many PCs support Device encryption, found under Settings, Privacy & security, Device encryption.

Where is my BitLocker recovery key stored?

Depending on setup, in Microsoft Entra ID, Active Directory, the user's Microsoft account, or wherever it was saved or printed. For business devices, store it in Entra ID or AD rather than a personal account.
