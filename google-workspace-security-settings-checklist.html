Google Workspace security settings checklist for small business

By William Todd, IT support and cybersecurity engineer · Updated 2026-11-22

The Google Workspace settings that matter most for a small business: enforce 2-Step Verification for everyone (security keys or passkeys for admins if you can), keep two or three super admin accounts that are used only for admin work, control which third-party apps can access company data, turn on Gmail's advanced phishing and malware protections, limit external sharing in Drive to what you need, and make sure someone reads the Alert center. All of these are in the Google Admin console (admin.google.com), and most take minutes.

Google changes admin console menus from time to time, so the paths below are a guide; if something has moved, use the search bar at the top of the Admin console.

Check the Security health page

Many plans include a Security health or security center page that lists settings against Google's recommendations. Like Microsoft's Secure Score (see Microsoft Secure Score), use it as a to-do list: fix the high-impact items first and don't chase every recommendation.

Before you enforce 2-Step Verification

  • Tell staff the date, and give them a week or two to enroll.
  • Make sure super admins are enrolled first and have backup codes stored securely, for example in the company password manager.
  • Plan for shared mailboxes and devices; consider Google Groups or delegation instead of shared logins.
  • Know how an admin can generate backup codes for a locked-out user.

Keep it current

  • Review admin roles and third-party app access every quarter.
  • Remove leavers on their last day and transfer their files (see the Google Workspace offboarding checklist).
  • If an account is ever compromised, follow the Google Workspace hacked account checklist.
  • Record changes so you can answer insurance questionnaires quickly (see the questionnaire guide).

Available features vary by Google Workspace edition. Check Google's admin help for your plan before relying on a setting.

Frequently asked questions

What security settings should I turn on in Google Workspace?

Enforce 2-Step Verification, keep a small number of dedicated super admin accounts, review third-party app access, turn on Gmail safety protections and DKIM, limit external sharing in Drive, and make sure Alert center notifications reach someone.

How many super admins should a small business have?

Usually two or three, each a named person with a separate account used only for admin work. Give everyone else narrower admin roles if they need any.

How do I enforce 2-Step Verification in Google Workspace?

In the Admin console under Security, Authentication, 2-step verification, allow enrollment, give staff a deadline, then turn on enforcement. Make sure admins are enrolled and have backup codes first.
