Microsoft 365 offboarding checklist

By William Todd, IT support and cybersecurity engineer · Updated 2026-11-21

Disabling the user in Microsoft 365 is only step one. Former employees often keep access through sessions that stay signed in, phones that still sync mail, forwarding rules, or app passwords. Use this checklist on their last day, in this order.

On the last day (in this order)

  1. Block sign-in in the Microsoft 365 admin center (Users › Active users › select user › Block sign-in).
  2. Sign out of all sessions. In the Entra admin center, open the user and choose Revoke sessions. This revokes their refresh tokens. Apps can keep working on an existing access token for up to about an hour, which is one more reason to do this first and check sign-in logs afterwards.
  3. Reset the password to a long random value, even though sign-in is blocked.
  4. Remove their MFA methods and any registered devices so they cannot be used for recovery.
  5. Wipe or remove mobile devices. If you use Intune, retire or wipe the device. If not, remove the mobile device partnership in Exchange.
  6. Check mailbox forwarding and inbox rules. Remove any forwarding to outside addresses and any rules that delete or redirect mail.
  7. Remove admin roles and group memberships, including distribution lists and Teams owners.

Handle the mailbox and files

  • Convert the mailbox to a shared mailbox if someone needs to keep reading it. Shared mailboxes under 50 GB do not need a license.
  • Set an auto-reply that tells senders who to contact instead.
  • Give the manager access to the user's OneDrive before you delete the account. OneDrive content is kept for a limited retention period after deletion.
  • Move files that matter to a SharePoint site the team owns.

Within the first week

  • Remove the license once the mailbox is converted and the data is moved.
  • Review sign-in logs for the account after the block date. Any successful sign-in is a red flag.
  • Rotate any shared passwords they knew, especially admin, banking, and vendor portals.
  • Review third-party apps they consented to with their account (Entra › Enterprise applications).

Frequently asked questions

Does blocking sign-in log a user out of Microsoft 365 immediately?

Not always. Existing sessions can keep working until their tokens expire, so you should also revoke sessions in Entra ID.

Should I delete a former employee's Microsoft 365 account?

Usually not right away. Block sign-in, convert the mailbox to a shared mailbox if needed, and move files first. Then remove the license.

Do shared mailboxes need a license?

Shared mailboxes up to 50 GB without an archive generally do not need a license. Larger mailboxes or archiving need one.
