Still on Windows 10? What a small business should do now

By William Todd, IT support and cybersecurity engineer · Updated 2026-11-21

Microsoft ended free support for Windows 10 on October 14, 2025. A Windows 10 PC that isn't enrolled in Extended Security Updates (ESU) no longer gets security fixes, so each one is "end-of-life software" on a cyber insurance application. The fix for each PC is one of three things: upgrade it to Windows 11 (free, if the hardware qualifies), replace it, or pay for ESU while you plan the move.

Here's how to find your Windows 10 machines, decide what to do with each one, and answer the insurer honestly in the meantime.

Step 1: Find every Windows 10 PC

On each PC, press Windows + R, type winver and press Enter. Or in PowerShell (read-only):

Get-ComputerInfo | Select-Object OsName, OsVersion, WindowsVersion

If your IT provider uses an RMM tool, ask for an OS version report; it takes them minutes. Don't forget front-desk PCs, imaging and lab PCs, the PC that runs the security cameras, and the old machine in the back that "just runs one program".

Step 2: Can it run Windows 11?

Windows 11 needs, among other things, TPM 2.0, Secure Boot capability and a supported processor (most PCs from roughly 2018 onward qualify, but check). Microsoft's free PC Health Check app gives a yes or no. To check TPM yourself in an admin PowerShell window:

Get-Tpm | Select-Object TpmPresent, TpmReady

TPM is sometimes present but switched off in the BIOS/UEFI settings; your IT provider can enable it.

About Extended Security Updates (ESU)

  • ESU gives a Windows 10 PC monthly security updates for up to three more years, through October 2028 for businesses.
  • For commercial customers, Microsoft's published pricing has been $61 per device for year one, doubling each year after that (year two $122, year three $244), and years are cumulative: enrolling in year two means paying for year one too.
  • ESU is security fixes only, with no new features or general support. It's a bridge, not a plan.

Pricing and terms can change, so confirm current details with Microsoft or your reseller before you budget.

Step 4: Answer the insurer honestly

Many cyber insurance applications ask whether you use end-of-life or unsupported software. For a Windows 10 PC:

  • Enrolled in ESU: it's still receiving security updates. Say so in a notes field if there is one, and keep the proof of ESU purchase.
  • Not enrolled: it's unsupported. Disclose it, and describe the plan and any compensating controls (isolated network, no internet access, no email).
  • Fix or document it before your renewal. See the questionnaire guide for wording.

Frequently asked questions

Is it safe to keep using Windows 10?

A Windows 10 PC that isn't enrolled in Extended Security Updates no longer receives security fixes, so new vulnerabilities stay unpatched. Upgrade, replace, or enroll it in ESU, and isolate any PC that must stay unsupported.

How much do Windows 10 Extended Security Updates cost for a business?

Microsoft's published commercial pricing has been $61 per device for the first year, doubling each year after that, with years cumulative. Confirm current pricing with Microsoft or a reseller.

How do I check if a PC can run Windows 11?

Use Microsoft's free PC Health Check app. Windows 11 requires TPM 2.0, Secure Boot capability and a supported processor, among other requirements.

Does Windows 10 count as end-of-life software for cyber insurance?

If it's not receiving security updates through ESU, it's generally considered unsupported. Disclose it accurately and describe your plan and compensating controls.
