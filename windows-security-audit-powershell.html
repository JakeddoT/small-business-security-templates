Windows security audit with PowerShell: what to check

By Jake Todd, IT support and cybersecurity engineer · Updated 2026-11-21

Before onboarding a client or after an incident, a quick baseline of each Windows PC catches the most common gaps. Run these read-only checks in an elevated PowerShell window.

Checks and example commands (PowerShell)

  • Defender status: Get-MpComputerStatus, check RealTimeProtectionEnabled and AntivirusSignatureAge.
  • Firewall profiles: Get-NetFirewallProfile
  • BitLocker: Get-BitLockerVolume
  • Last patch: Get-HotFix | Sort InstalledOn -Desc | Select -First 5
  • Local admins: Get-LocalGroupMember Administrators
  • SMBv1: Get-SmbServerConfiguration | Select EnableSMB1Protocol
  • Listening ports: Get-NetTCPConnection -State Listen
  • RDP enabled: check fDenyTSConnections under HKLM:\System\CurrentControlSet\Control\Terminal Server

Frequently asked questions

How do I check if BitLocker is on with PowerShell?

Run Get-BitLockerVolume in an elevated PowerShell window and check ProtectionStatus.

How do I check if SMBv1 is enabled?

Run Get-SmbServerConfiguration | Select EnableSMB1Protocol in PowerShell.
