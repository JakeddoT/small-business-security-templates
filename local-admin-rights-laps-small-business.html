Local admin rights and Windows LAPS: a small business guide

By William Todd, IT support and cybersecurity engineer · Updated 2026-11-21

Everyday user accounts shouldn't be local administrators on their PCs, and the built-in admin account on each PC shouldn't share one password across the office. Check who's in each PC's Administrators group with Get-LocalGroupMember -Group Administrators, remove the staff accounts that don't need it, and use Windows LAPS (Local Administrator Password Solution) so every PC gets its own long admin password that changes automatically and is stored in Microsoft Entra ID or Active Directory. Windows LAPS is built into Windows and rolled out through Windows updates starting in April 2023, and backing up to Entra ID works with the free tier.

Why it matters

  • Malware runs with the user's rights. If the user is an admin, so is anything they open, which makes it far easier to install ransomware or turn off security tools.
  • Scams need admin rights. Fake IT support callers often need to install software; a standard user can't (see fake IT support calls).
  • One shared admin password is one key to every PC. If an attacker gets it from one machine, they can use it on all of them.
  • Insurers ask. Cyber insurance questionnaires often ask about admin rights and privileged access (see the questionnaire guide).

Step 1: find out who's an admin

On each PC, in an elevated PowerShell window:

Get-LocalGroupMember -Group Administrators

Record the result in your asset inventory. You're looking for everyday staff accounts, old accounts of people who've left, and accounts you don't recognize. The Windows security audit with PowerShell covers this and other settings in one pass.

Step 2: decide who actually needs admin

WhoUsually
Office staffStandard user. IT installs software for them.
Owner or managerStandard user for daily work, plus a separate admin account used only when needed
IT providerTheir own named admin accounts or a managed tool, not a shared password
Apps that "need admin"Ask the vendor; most modern apps don't. Fix the app's permissions rather than making the user an admin

Step 3: remove the rights

  • Tell staff first, and agree how they'll request software or printer installs.
  • Remove one person or one PC at a time, and check their apps still work.
  • On a PC that isn't centrally managed, an admin can remove a user with Remove-LocalGroupMember -Group Administrators -Member "PCNAME\username" (local account) or through Settings → Accounts → Other users. With Intune or Group Policy, your IT provider can manage the group centrally.
  • Make sure at least one working admin account remains before removing others.

Step 4: set up Windows LAPS

Windows LAPS gives the PC's local administrator account a unique, random password, changes it on a schedule, and stores it where authorized admins can look it up.

Notes from Microsoft's documentation worth knowing: Entra ID doesn't accept LAPS passwords until an admin turns the feature on at the tenant level, and if a device is deleted from Entra ID its stored password is lost. Ask your IT provider to test retrieving a password before relying on it.

Step 5: keep it that way

  • Re-check admin group membership every quarter and after anyone leaves (see the offboarding checklist).
  • Limit who can read LAPS passwords to the few people who need them.
  • Use MFA on every account that can manage devices or read LAPS passwords (see the MFA rollout plan).
  • Note the change in your acceptable use policy: staff don't install software themselves.

Frequently asked questions

Should employees have local admin rights?

Usually not. Standard user accounts limit what malware and scammers can do. Give admin rights only to the few people who need them, ideally through a separate admin account.

How do I see who is a local admin on a Windows PC?

Run Get-LocalGroupMember -Group Administrators in an elevated PowerShell window, or check Computer Management under Local Users and Groups where available.

What is Windows LAPS?

A Windows feature that gives each PC's local administrator account a unique, automatically rotated password and backs it up to Microsoft Entra ID or Active Directory so authorized admins can retrieve it.
