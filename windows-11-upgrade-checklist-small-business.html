Windows 11 upgrade checklist for small business PCs

By William Todd, IT support and cybersecurity engineer · Updated 2026-11-21

To upgrade small-business PCs to Windows 11 safely: check each PC is eligible (a supported 64-bit CPU, TPM 2.0, UEFI with Secure Boot, 4 GB RAM and 64 GB storage), back up its data, save its BitLocker recovery key, confirm your business apps and printers work on Windows 11, then upgrade a pilot PC before the rest, in waves. PCs that can't meet the requirements need replacing or, for a limited time, Windows 10 extended security updates.

Windows 10 reached end of support in October 2025, so PCs still on it don't get regular security updates unless they're enrolled in Extended Security Updates (see Windows 10 end of support options). Cyber insurers increasingly ask whether you run unsupported operating systems.

Microsoft's free PC Health Check app gives a simple yes or no for each PC. Sometimes a PC fails only because TPM or Secure Boot is turned off in the firmware settings; your IT provider can check that before you write the PC off. Microsoft's own consumer upgrade tools are meant for PCs not managed by an IT administrator; if you have an IT provider or device management, follow their process.

Step 3: before each upgrade

  1. Back up the user's files and confirm they're in OneDrive, Google Drive or your backup (restore test).
  2. Save the BitLocker recovery key somewhere you can reach if the PC asks for it, such as your Microsoft Entra or Microsoft account, or your IT provider's records (how to check BitLocker).
  3. Check business apps: accounting, practice management, POS back office, VPN client, scanner and label printer software. Ask vendors to confirm Windows 11 support.
  4. Check printers and scanners have Windows 11 drivers.
  5. Install pending Windows 10 updates and make sure there's enough free disk space.
  6. Schedule it out of hours; an upgrade can take an hour or more and several restarts.

Step 4: upgrade a pilot, then waves

  • Upgrade one or two PCs first, ideally people who will report problems, and use them for a week.
  • Then upgrade the rest in small groups, not all at once, so one problem doesn't stop the whole office.
  • Eligible PCs are usually offered the upgrade through Windows Update (Settings → Windows Update). Your IT provider may use device management to schedule it instead.

Step 5: after the upgrade

  • Confirm BitLocker is still on, antivirus/EDR is running, and Windows Update shows the PC is current.
  • Check that the user's apps, printers and mapped drives work.
  • Run a security check: firewall on, no unexpected local admins, screen lock set (see the Windows security audit with PowerShell).
  • Update the asset inventory with the new OS version.

PCs that can't upgrade

Replace them, enroll them in Windows 10 Extended Security Updates while you wait, or retire them. Don't keep an unsupported PC handling email, banking or customer data indefinitely. When it's replaced, wipe it properly (see secure computer disposal). Microsoft doesn't recommend installing Windows 11 on hardware that doesn't meet the requirements, and says such PCs may not receive updates.

Frequently asked questions

How do I know if a PC can run Windows 11?

Run Microsoft's free PC Health Check app, or check for a supported 64-bit CPU, TPM 2.0, UEFI with Secure Boot, at least 4 GB RAM and 64 GB storage.

What should I do before upgrading to Windows 11?

Back up the user's files, save the BitLocker recovery key, confirm business apps and printers support Windows 11, install pending updates, and upgrade a pilot PC first.

What if my PC isn't eligible for Windows 11?

Check whether TPM or Secure Boot is just turned off in the firmware. If the hardware really isn't supported, plan to replace it and use Windows 10 Extended Security Updates in the meantime.
